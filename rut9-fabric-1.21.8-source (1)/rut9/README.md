# Русский T9 для Minecraft 1.21.8 (Fabric)

Автокоррекция и предсказание слов для чата. Всё работает локально, без интернета.

## Сборка
Нужны JDK 21 и Gradle 8.14+ (Fabric Loom 1.11).

    gradle wrapper --gradle-version 8.14     # один раз, создаст ./gradlew
    ./gradlew build                          # jar: build/libs/rut9-1.0.0.jar

Версии в `gradle.properties` сверьте с https://fabricmc.net/develop/ (выбрать 1.21.8).
Установка: положите `rut9-1.0.0.jar` и Fabric API в `mods/`.

## Управление
- Пробел / знак препинания — автозамена последнего слова.
- Backspace сразу после замены — отмена (слово больше не исправляется).
- Клик по варианту, Tab (первый вариант) или Alt+1/2/3 — выбрать предложение.
- F8 — скрыть/показать панель.
- Enter — перед отправкой: исправляется последнее слово, ставятся запятые и «?».
- Команды `/t9 <enabled|panel|autocorrect|predict|learn|punctuation|period|capitalize|layout|dark|tab|reset>`.
- В командах (текст на «/») мод ничего не трогает.

## Файлы пользователя (config/rut9/)
- `config.json` — настройки; `user_model.json` — личный словарь и n-граммы игрока;
- `dictionary.txt` — свой словарь (`слово число` на строку); `bigrams.txt` — свои биграммы (`w1 w2 число`).

## Архитектура
engine/: Lexicon (словарь + SymSpell + префиксный поиск) → Corrector (расстояние Дамерау–Левенштейна,
модель опечаток по ЙЦУКЕН, контекст) → Morphology (предлоги, согласование местоимений) →
Predictor (личные и встроенные n-граммы, частоты, тематический слой Topics) → UserModel (обучение) →
Punctuator, LayoutFixer. ui/: ChatT9 (логика поля ввода) + SuggestionPanel. mixin/ChatScreenMixin — 4 точки входа в ChatScreen.
Для книг/табличек/наковальни достаточно добавить миксины, вызывающие ChatT9-подобный контроллер с нужным TextFieldWidget.

## Ограничения
- Встроенный словарь — небольшой стартовый набор (≈1000 слов). Для реального качества подключите
  большой частотный словарь (например, OpenCorpora / НКРЯ) через `dictionary.txt`.
- Нейросетевая языковая модель не включена; «семантика» — n-граммы + тематические правила (`topics.txt`).
